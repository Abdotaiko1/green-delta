## Visual Language
- Core visual signature: Traffic-light badge system (success/warning/danger) for status indicators, ensuring operational priorities (elevators, faults, maintenance) are instantly visible.
- Material & depth: Flat white content panels on a light grey shell (#F5F7FA). No drop shadows; depth is strictly indicated by surface lightness.
- Containers & buttons: Hairline dividers replace explicit card borders. Sharp edges or very slight rounding (2px).
- Layout rhythm: KPI numbers serve as oversized visual anchors in the dashboard. Dense, grid-based alignment emphasizing data hierarchy over decoration.

## Animation
- Entrance: Fast, simple fade-in for data tables (150ms, ease-out). No sweeping page-level entrance animations.
- Interaction: Minimal feedback (background color darken on hover, 100ms).
- Scroll / transition: None. Immediate data switches.

## Forbidden
- No large flat color fills; primary/accent used only as small focal accents.
- Do not use generic drop shadows or glowing effects; keep the interface strictly flat.
- No looping decorative animations or visual noise that distracts from reading data.

## Additional Notes
- All user-visible copy follows the user's language preference (Arabic), with Right-to-Left (RTL) layout support.
- Dashboard heavily relies on data tables with editorial line rules instead of cell borders.
